# 《师傅，你先别给我换》三人版素材说明

## 角色固定

- 维修师傅：38 岁左右，深色维修工作服，轻微机油痕迹，冷静、干练、带一点干幽默。
- 男车主：31 岁左右，白色卷袖衬衫、深色长裤，自信但容易被反转惊到。
- 女生：29 岁左右，米白西装、浅色内搭、深色长裤；同行者兼解释者，负责开场拦停、递产品和最后说明。

三人面貌、发型、服装以 `reference/character-lock.png` 为连续性基准。

## 产品固定

- 空调滤芯：蓝色折叠滤材、白色侧框，用于副驾驶储物箱后方。
- 空气滤芯：白色折叠滤材、黑色橡胶框，用于发动机舱。
- 包装：以用户提供的白底、发动机舱照片、深蓝底栏、黄色信息块包装为外观参考。

产品结构与视角以 `reference/product-lock.png` 为连续性基准。包装小字是 AI 参考重建，正式广告必须换成实拍包装或准确平面文件。

## 使用规则

1. 先用首帧锁定人物位置、景别、光线和产品方向，再用尾帧设计动作终点。
2. 后续视频生成必须同时引用人物固定图、产品固定图和对应镜头首帧。
3. 字幕、品牌字和包装小字统一在后期添加，不依赖生成图内文字。
4. 车型内部结构存在差异，实际拍摄前应确认储物箱拆卸方式和滤芯安装方向。
