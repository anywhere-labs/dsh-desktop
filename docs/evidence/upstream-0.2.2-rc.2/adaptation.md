# rc.2 适配核对

来源：https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.2-rc.2

目标提交：`ddac96760b6edf8fa0fe17cbdcf0b512f4c12b2c`。基于 master `233b76c65d2a83a777a96419d798cb5582acb8f7`，Beta 与 Next 均从 rc.1 升级 rc.2；Stable 保持 0.2.1-rc.3。Desktop 版本沿用主线：Beta 2.0.22-beta.1、Next 2.0.22-next。

原则：官方已覆盖则移除本地实现；部分覆盖只补剩余差异。以下区分计划与已验证结果，不将依赖升级等同于功能验收。

官方 runtime 构建：10/10 门禁通过，374 个包。Beta 与 Next 的构建、类型检查、全量单测、真实 Host smoke、运行时隔离及 Electron safe-home 检查通过。下列“直接采用”表示使用官方实现并通过组合门禁，不代表逐项完成图形界面人工验收。

Tokens Anywhere 不纳入本次桌面产品。旧工作区误从未合并的功能分支起步；现已从 master 重建，只迁移上游适配和恢复修复，没有引入 Tokens 提交、源码、workspace 或默认加载入口。旧成果保存在 backup/upstream-adaptation-before-master（5ffe9d6469），新分支为 codex/upstream-rc2-from-master。自有桌面更新通道、下载与安装交互保持原实现。中间版本逐项核对见 [alpha.3 / rc.1](intermediate-releases.md)。
