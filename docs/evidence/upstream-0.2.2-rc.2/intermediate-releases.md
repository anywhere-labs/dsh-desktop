# alpha.3 / rc.1 中间版本逐项核对

早期适配从 alpha.2 开始，现已在 master 的 rc.1 基础上重建，Beta／Next 均升级 rc.2。此表保留历史迁移追溯，按两份 release 中文列表顺序编号，记录中间契约迁移。重复条目最终只采用 rc.2 实现。代码与验证总览见 [rc.2 清单](adaptation.md)。

“组合门禁”指构建、类型检查、单元测试和真实 Host 启动；不等于所有 UI、远端服务或平台行为都已验收。官方 SDK／SSH 等不由 Desktop 自行实现的能力，随运行包采用，不宣称已迁移外部用户扩展。
