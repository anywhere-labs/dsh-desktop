## 1. 需求(用户原话归纳)

1. 功能与原桌面端对齐(模型来源除外:模型由服务端配置)。
2. 服务端的服务商 = 视频剪辑的默认服务商(媒体走服务端,减少 DeepSeek 官方 API 消耗)。
3. 集成后增加:在线素材与素材库的操作、服务端技能(官方技能之外)。
4. 其它自定义(创作模式/媒体工具/浏览器等既有视图不受影响)。
5. 会话要有交互,会话里的样式与原桌面端一致;素材/时间/当前选中要能引用(注入上下文)。

## 3. 过程规则(2026-10-23 复盘后新增,长期有效)

1. **运行时行为改动,先出包自测该项,通过才提交** — 静态门禁(typecheck/单测/变体门禁)不构成完成。
2. **拆兜底前,替代品必须在同一包里验证通过**(顺序:先验证替代 → 再退役旧路径)。
3. 验收中发现的每一处不一致,先归类(桥数据/UI 消费/服务端契约),再修;修完把本表对应行更新。
