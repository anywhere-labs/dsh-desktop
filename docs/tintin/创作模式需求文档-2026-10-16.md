## 1. 背景与目标

仿即梦桌面端「输入会话」形态（问候语 + 生成/画布 tab + 带 `/` 技能、`@` 主体的大输入框 + 技能芯片行），在 TinTin 客户端落地为**创作模式**：一个自定义技能预设驱动的创作入口，把"一段想法"对接到服务端已有的文本生成、分镜、口播、生图、成片能力上。

**关键事实（即梦实测）**：即梦桌面端是 Electron 壳，技能列表由服务端下发、本地无缓存——因此本需求的技能体系按**客户端本地自定义预设**设计（用户可增删改），不依赖服务端下发；服务端已有的 `/skills` 接口仅作为后续可选的云同步项（§6-P5）。

## 2. 入口与信息架构（已实施，本期不动）

- **独立视图** `creation`：左侧栏入口「创作模式」，置于「运营工具」**之上**（用户裁决 2026-10-16，见截图批注）。
- **不占用媒体工具网格卡位**（同裁决，已从媒体工具网格摘除）。
- 视图由 `dsh-tintin-media-bundle` 注册提供（`window.__tintinViews 'creation'`），KeepAlive 语义与 ops/media 一致；跨视图跳转走 chrome 暴露的 `window.__tintinActivateView`（client.js，2026-10-16 新增白名单式激活口）。

## 4. 技能预设模型（客户端侧契约）

```ts
interface CreationSkill {
  id: string          // 'sk-...'；内置 id 固定（sk-storyboard 等）
  name: string        // 显示名，'/' 令牌按名匹配（精确>前缀）
  emoji: string
  template: string    // 占位符：{{输入}} {{主体}}（主体=顿号连接的名称列表）
  tool?: string       // 可选绑定媒体工具卡 id（storyboard/copywriting-montage/...）
  builtin?: boolean   // 内置：可编辑不可删
}
```

内置 7 技能及其绑定：电影级长镜头运镜→imitation-video、创作分镜→storyboard、风格大师→（自动）、叙事短片导演分镜→storyboard、微表情导演→（自动）、电影广告全能导演→copywriting-montage、系列图生成→cover-design。
